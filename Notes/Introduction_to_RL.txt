Reinforcement Learning (RL):
- The main concept on which RL works is an agent learning by trial and error.
- Unlike other types of machine learning, the agent is not explicitly told what the correct action is. It must discover which actions yield the most reward.
- Rewards may be delayed, meaning an action taken now can result in positive or negative rewards much later in the future (after multiple steps in a trajectory).

Environment: The world that the agent lives in and interacts with.
The Loop: Agent sees a state -> takes an action -> receives a reward signal and the next state from the environment.
The environment can control when to ask the agent to act.

Key Terms:
1) State (s): A complete description of the world
2) Observation (o): A partial description of the state 
3) Action Space: The set of all valid actions available to the agent
4) Trajectories: A sequence of states and actions over time 
5) Policy: Rule by which agent takes action
6) Return: Total reward over a trajectory
7) Discount Factor: Factor to ensure the mathematical sum of future rewards converges

Value Functions:
- Functions that estimate the expected return to predict how good a situation is
- State-Value Function: Measures how good it is to be in a specific state
- Action-Value Function: Measures how good it is to take a specific action in a specific state
- Optimal Value Functions: The maximum possible expected return an agent can achieve

Exploration vs. Exploitation:
- The fundamental trade-off the agent faces while learning
- Exploration: Trying out new, untested actions to gather more information about the environment
- Exploitation: Using known information to choose the action that is currently expected to yield the highest reward
- An agent must balance both i.e exploring too much wastes time, but exploiting too early means missing out on potentially better strategies
